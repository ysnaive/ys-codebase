# 四段式版本規範說明書 (SemVer v4 Specification)

> 適用模組：`core`  
> 模組路徑：`source/core/core/semver.py`  
> 知識庫維度：維度 3（中觀專題手冊 Topic Docs）  
> 最後更新：2026-08-25  

---

## 1. 核心定義與格式

YS-Codebase 採用**四段式語意化版本體系**：

$$\text{Format: } \text{major}.\text{minor}.\text{patch}.\text{revision}[-\text{prerelease}]$$

- **`major` (主版本號)**：破壞性變更、重大架構重構（例如：`1.0.0.0` ➔ `2.0.0.0`）。
- **`minor` (次版本號)**：向下相容的功能新增、擴充 API（例如：`1.0.0.0` ➔ `1.1.0.0`）。
- **`patch` (修訂號)**：向下相容的問題修復、內部最佳化（例如：`1.0.0.0` ➔ `1.0.1.0`）。
- **`revision` (構建修訂號)**：
  - **數值修訂號**（如 `1.0.0.1`）：微小 Bugfix 或緊急熱修復，**尾號在比較時不具獨立大小意義**。
  - **`build` 標記**（如 `1.0.0.build`）：本地開發未發布產物。
- **`prerelease` (預發布標籤)**：可選字串（如 `2.0.0-beta.1`）。

---

## 2. 比較與排序規則 (Precedence Rules)

1. **前三段數值決定大小**：版本優先順序嚴格由 `(major, minor, patch)` 三元組數值大小決定（例如：`1.10.0.0 > 1.9.0.0`）。
2. **預發布標籤**：正式版優先於預發布版（`1.0.0.0 > 1.0.0-beta`）。
3. **Revision 比較規則**：
   - 當 `(major, minor, patch)` 相同時，數值型 revision 視為同一主要版本。
   - 數值型 revision 優先於 `build`（`1.0.0.0 > 1.0.0.build`）。
4. **自動正規化 (Zero Normalization)**：
   - 三段式版本字串（如 `"1.0.0"`）輸入解析器時，自動正規化為 `(1, 0, 0, 0, "")`，標準字串表示為 `"1.0.0.0"`。

## 3. 範圍約束與運算子支援

| 運算子 | 語意說明 | 範例 | 匹配範圍 |
| :--- | :--- | :--- | :--- |
| `==`, `=` | 精確匹配 | `==1.2.0` | `1.2.0.0` ~ `1.2.0.x` |
| `!=` | 排除版本 | `!=1.0.0.0` | 排除 `1.0.0.0` |
| `>`, `>=` | 大於 / 大於等於 | `>=1.0.0` | 大於等於 `1.0.0.0` |
| `<`, `<=` | 小於 / 小於等於 | `<2.0.0` | 小於 `2.0.0.0` |
| `~=`, `^` | 相容性範圍 (同 Major 鎖定) | `^1.0.0` | `>=1.0.0.0, <2.0.0.0` |
| `*`, `None` | 通配符號 | `*` | 任意版本 |
