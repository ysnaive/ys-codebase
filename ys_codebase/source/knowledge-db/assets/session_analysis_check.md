##### 知識庫檢索與調用圖譜效益評測 (knowledge-db)

檢核當前對話中 `knowledge-db` 工具組（`search`、`callers`、`callees`、`impact`、`status`）的使用情況與效益：

- [ ] **調用統計與時機**：統計各工具調用次數，評估是否於代碼檢索、架構探索或調用排查時及時觸發，有無漏用或過度調用。
- [ ] **工具效益與 Token 估算**：相較全庫文字搜尋與逐檔閱讀，預估使用語意切片所節省的 Token 與對話往返輪次。
- [ ] **檢索精準度**：評估目標符號或代碼切片是否命中前 3 順位，對解決問題之實質幫助。

**標定產出格式**：
```markdown
- **知識庫檢索與調用圖譜效益 (knowledge-db)**：
  - **調用次數**：`search`: [X] 次, `callers`/`callees`: [Y] 次, `impact`: [Z] 次, `status`: [W] 次
  - **時機合理性**：[合理 / 偏多 / 偏少]（簡要說明）
  - **效益對比**：預估相較逐檔探索節省約 [N] Tokens
  - **檢索精準度**：Top 3 命中率 [P]%，解題貢獻度 [高 / 中 / 低]
```
