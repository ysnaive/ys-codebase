# 上下文熱啟動工作流 (Context Initialization Workflow)

本工作流用於在新 Session / Chat 啟動時，快速探測環境、初始化專案語意記憶與規範索引。

---

## 1. 執行步驟與防呆指引 (Step-by-Step Execution)

1. **探測環境狀態**：
   - 檢查當前工作目錄與專案環境。
   - 檢視 `AGENTS.md` 或本模組導出的 `standards/`。
2. **語意地圖載入**：
   - 探測並定位專案語意 URI 與工作區結構。
   - 保持最小開銷，建立與開發者的共識基線。
