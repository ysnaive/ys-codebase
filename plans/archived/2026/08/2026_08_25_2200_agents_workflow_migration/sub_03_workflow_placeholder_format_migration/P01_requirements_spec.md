## 1. 功能需求清單 (Functional Requirements)

| 需求編號 | 需求名稱 | 詳細規格說明 | 對應 P00 語意 |
| :--- | :--- | :--- | :---: |
| **FR-01** | **插入佔位符語法解析** | `ArtifactCompiler` 必須採用正則 `r"__@\{\s*([A-Za-z0-9_]+)\s*\}__"` 精確匹配並提取 Token 錨點名稱。 | `[P00:DR-01]` |
| **FR-02** | **路徑佔位符語意保留** | 編譯器必須識別 `__#{uri}__` 語意標籤（正則 `r"__#\{\s*([^}]+)\s*\}__"`），並於產物文檔中 100% 保持原樣保留，不進行內容展開。 | `[P00:DR-02]` |
| **FR-03** | **正則微量空格容錯** | 佔位符解析必須允許大括號內部微量空格（例如 `__@{ TOKEN }__` 與 `__@{TOKEN}__` 視為等價並均可精準匹配）。 | `[P00:DR-01]` |
| **FR-04** | **5-Step 狀態機三模式注入** | `resolve_single_artifact()` 狀態機必須在 `__@{token}__` 錨點處正確執行 `replace`、`below`、`above` 三種模式注入。 | `[P00:DR-03]` |
| **FR-05** | **解算後殘留標籤自動抹除** | 每一輪解算或無匹配 insert 時，必須乾淨抹除文本中對應的 `__@{token}__` 錨點標籤行，保證最終產物無任何未解算錨點殘留。 | `[P00:DR-03]` |
| **FR-06** | **標準模板庫 1:1 語法全面遷移** | `source/agents-workflow/assets/templates/` 下所有 P01~P07 標準模板全面將舊標頭標籤替換為 `__@{PHASEXX_STANDARD_HEADER}__`。 | `[P00:DR-04]` |
| **FR-07** | **規範與工作流文檔 1:1 遷移** | `DevelopmentStandards.md`（`__@{PROJECT_SPECIFIC_STANDARDS}__`）與 `ContextInit.md`（`__@{DYNAMIC_CONTEXT_MAP}__`）全面遷移為新語法。 | `[P00:DR-04]` |
| **FR-08** | **舊語法完全升級清除** | 編譯器徹底移除舊 `<!-- __TOKEN__ -->` 匹配邏輯，維持單一真相來源純淨化。 | `[P00:DR-04]` |

## 2. 邊界與例外清單 (Edge Cases & Exceptions)

| 例外編號 | 情境名稱 | 觸發條件與防禦策略 | 預期行為 | 對應 P00 語意 |
| :--- | :--- | :--- | :--- | :---: |
| **EC-01** | **自指死鎖防護** | 注入之內容自身包含同名 `__@{token}__` 標籤。 | 狀態機單輪僅替換當前快照中已識別之標籤，跳過注入內容自我展開，防止無窮遞迴死鎖。 | `[P00:DR-03]` |
| **EC-02** | **無匹配 Token 錨點** | 模板中存在 `__@{UNKNOWN_TOKEN}__` 但系統中無任何 donor 提供對應 insert。 | 編譯器於 Step 3 乾淨抹除該標籤行，不報錯中斷編譯流程。 | `[P00:DR-03]` |
| **EC-03** | **路徑佔位符不變性** | 文檔中包含多個 `__#{uri}__` 或包含複雜語意 URI（如 `__#{module.root://...}__`）。 | 編譯前後所有路徑佔位符內容與位置 100% 保持不變。 | `[P00:DR-02]` |
| **EC-04** | **多輪遞迴與上限保護** | 注入內容引入了新的其他 `__@{OTHER_TOKEN}__` 標籤。 | 狀態機在 `max_passes` (預設 10 輪) 限制內多輪收斂展開，超限時優雅停止並抹除未解算標籤。 | `[P00:DR-03]` |

## 3. 非功能性需求 (Non-Functional Requirements)

- **NFR-01 (Markdown 可視性)**：全新佔位符語法在標準 Markdown 預覽（IDE 檢視器、GitHub 等）模式下原生可視，不再被 HTML 渲染引擎自動隱藏。
- **NFR-02 (編譯性能)**：單一檔案多輪遞迴解算耗時維持在 1ms 以內，全量 16+ 資產編譯耗時小於 50ms。
- **NFR-03 (零臆測與回歸保證)**：所有資產 100% 遷移，全系統回歸測試維持 100% Passed。
