## 1. 介面契約清單 (Interface Inventory)

| 介面 / 類別名稱 | 所屬檔案路徑 | 存取層級 | 核心職責 |
| :--- | :--- | :---: | :--- |
| `dev.scripts.cli.*` | `source/dev/scripts/cli.py` | Public | 提供 `create`, `check`, `build`, `test`, `release`, `release_check`, `release_git`, `bump_*` 精確命令函式 |
| `knowledge_db.scripts.cli.*` | `source/knowledge-db/scripts/cli.py` | Public | 提供 `status`, `scan`, `bundle`, `index`, `search`, `callers`, `callees`, `impact`, `clean` 精確命令函式 |
| `agents_workflow.scripts.cli.*` | `source/agents-workflow/scripts/cli.py` | Public | 提供 `plan` (複合分支)、`plan_*` (底線平鋪函式) 與 `release`, `compile`, `roadmap`, `tokens`, `list`, `init` 精確命令函式 |
| `core.commands.dispatcher.dispatch_local` | `source/core/core/commands/dispatcher.py` | Internal | 本地執行派發器：執行目標精確函式，過渡層拔除後若無函式直接拋出 EC-05 (127) |
